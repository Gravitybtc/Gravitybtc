# GravityBTC

Independent verification, certification, retrieval, and structured record workflows for Bitcoin activity.

## Services

### Case

Understand Bitcoin activity.

### Certification

Independently certify records.

### Relay

Create retrievable transaction-reference continuity.

### Retrieve

Access completed Gravity records using an Invoice ID.
