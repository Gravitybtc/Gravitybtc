# Gravity Verification Standard v1.0
Standard ID: GVS-1
Status: Canonical
Maintainer: GravityBTC

## Purpose

The Gravity Verification Standard defines how Gravity records, publications, certifications, and evidence packages are independently checked.

Verification must confirm:

1. The artifact exists.
2. The artifact has a SHA256 hash.
3. The hash matches the published verification record.
4. The verification record identifies the artifact.
5. The verification path is public or reproducible.

## Required Verification Materials

- canonical artifact
- SHA256 hash
- verification record JSON
- public URL or retrieval path
- issuer identity
- timestamp
- record status

## Verification Result

A verification result must return one of:

- verified
- mismatch
- unavailable
- superseded
- revoked

## Gravity Principle

Verification is not a claim.

Verification is a reproducible process.
